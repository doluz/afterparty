# Code of conduct

Afterparty follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, and make this a welcoming project for everyone, whatever their background or experience.
Harassment, insults and personal attacks are not accepted, in issues, pull requests or any other project space.

To report a problem, use GitHub's private vulnerability reporting on the **Security** tab, or contact the maintainer through their GitHub profile.
The maintainer will review each report in confidence.
